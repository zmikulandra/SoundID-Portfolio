# Screenshot checklist

Add PNG or JPG images with simple lowercase filenames.

Recommended files:

- `dashboard.png`
- `editor.png`
- `waveform.png`
- `track-controls.png`
- `library.png`
- `export.png`

Before uploading, check that screenshots do not expose:

- Email addresses
- Tester information
- Private file names
- Personal recordings
- Notifications
- Device identifiers
