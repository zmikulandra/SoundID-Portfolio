# Code sample preparation

The files in this directory are safe placeholders.

Before publishing:

1. Copy only a small, focused excerpt from the private project.
2. Remove package names that expose private structure if desired.
3. Remove secrets, paths, signing configuration, API keys, and personal data.
4. Remove unrelated dependencies.
5. Add a short comment explaining what the excerpt demonstrates.
6. Confirm that no proprietary third-party code is included.
7. Keep the private repository and its Git history separate.

A good sample should be understandable in approximately two to five minutes.
